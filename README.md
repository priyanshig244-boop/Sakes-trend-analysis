# Customer Churn / Sales Trend Analysis

## Project Overview
This project focuses on analysing e-commerce sales data to identify revenue trends, best-performing product categories, and valuable customers.

The project uses Python and data analysis libraries to explore sales patterns, calculate monthly revenue, compare product categories, and perform customer analysis using the Pareto Principle.

## Objectives
- Analyse e-commerce sales data.
- Identify monthly revenue trends.
- Calculate month-over-month sales growth.
- Compare product categories based on revenue.
- Identify the top 10% of valuable customers.
- Generate business recommendations based on data insights.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
A simulated e-commerce sales dataset containing:
- Order Date
- Customer ID
- Product Category
- Order Amount

The dataset contains 2,000 orders generated using Python and NumPy.

**Note:** This project uses generated sample data, not real customer information.

## Project Workflow
1. Import required Python libraries.
2. Generate the e-commerce sales dataset.
3. Perform data exploration and cleaning.
4. Extract date features such as month, weekday, and quarter.
5. Analyse monthly revenue and growth.
6. Compare product categories using GroupBy.
7. Create monthly category pivot tables.
8. Identify valuable customers using Pareto Analysis.
9. Visualise sales trends and customer contributions.
10. Provide business recommendations.

## Key Analysis
- Monthly Revenue Analysis
- Month-over-Month Growth
- Product Category Performance
- Pivot Table Analysis
- Top Customer Analysis
- Pareto Principle (80/20 Analysis)

## Business Recommendations
- Introduce loyalty rewards for high-value customers.
- Focus marketing efforts on high-revenue product categories.
